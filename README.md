# 🌿 Trellis — Adaptive Learning Platform for Systems & Cloud Architects

Trellis is an AI-powered, living competency platform designed for software, systems, and cloud architects. Rather than relying on rigid, linear roadmaps, Trellis evaluates real-world competencies, identifies high-leverage growth gaps across a dynamic 6-axis skill radar, and cultivates an organic milestone lattice that adapts as you learn.

---

## ✨ Features & Components

- **🌌 Aurora Hero & Skill Radar**: GLSL aurora gradient hero with luminous orb mark, floating telemetry badges, and interactive skill radar preview.
- **📑 Auto-Cycling Features Showcase**: Timed tabbed showcase with pause-on-hover and crossfading competency mockups.
- **🌟 Customer Story Spotlight & Author Rail**: Testimonial story cards with interactive author list and progress bars.
- **🔐 Split & Magic-Link Authentication**: 
  - **Auth 2**: Split layout with dark emerald mesh backdrop and OAuth integrations (Google & GitHub).
  - **Auth 5**: Passwordless magic link with animated check-your-inbox state swap and resend cooldown.
- **🧭 Vertical Side Navigation Rail**: Left-anchored vertical rail with cursor Y-distance dock-style spring scaling and horizontal tooltips.
- **🤖 Evidence-Mapped AI Guide**: Pinned context sources bar and clickable per-message citation badges mapping assertions to technical RFCs and literature.
- **👤 Profile & 3D Architect Pass**: Combined profile card with diversity vector avatars, bio, quick actions, and an interactive 3D holographic tilt credential pass.
- **🔥 Activity Streak Heatmap**: 24-week commit-style activity matrix with keyboard arrow navigation and day tooltips.
- **📅 Study Calendar & Agenda**: Full month calendar with event dots and a filterable scrollable day agenda.
- **🗂️ Expandable Course Modal Cards**: Smooth `layoutId` course cards expanding into full syllabus modal sheets with lab launchers.

## 🚀 Quick Start (Local Setup)

### 1. Prerequisites
- **Node.js** v18 or higher (v20+ recommended)
- **npm** or **yarn** / **pnpm**

### 2. Clone the Repository
```bash
git clone https://github.com/RahulR1826/trellis-frontend.git
cd trellis-frontend
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start Development Server
```bash
npm run dev
```
Open **[http://localhost:8085](http://localhost:8085)** in your browser.

---

## 🛠️ Scripts

- `npm run dev`: Starts the local development server with live reload on port 8085.
- `npm run build`: Bundles the client and server for production with zero errors.
- `npm run start`: Runs the compiled production server.
- `npm run lint`: Performs a full TypeScript type check.

- **Markdown & Code**: `react-markdown` + `remark-gfm`
- **Effects**: `canvas-confetti`
